## 3. Struktur situs sekarang

```
/id/  + /en/   → 14 halaman × 2 bahasa = 28 halaman
                 index, about, categories, schedule, tickets, race-pack,
                 race-day, rules, faq, news, gallery, partners, contact, privacy

assets/css/    → tokens, base, components, pages (design system)
assets/js/     → data.js (SSOT), main.js (partial inject, modal, lang-switch,
                 hreflang, JSON-LD), countdown.js
assets/partials/ → header/footer/modal-register × {id, en}
assets/img/    → logo (8 SVG), graphics (22 file), bg mesh (8 WebP)

Dockerfile + Caddyfile → deploy Railway (Caddy statis, redirect / → /id/)
```

### Prinsip arsitektur yang dipegang
- **`data.js` = satu-satunya sumber fakta.** Tidak ada tanggal/harga/kuota yang di-hardcode di HTML. Setiap fakta dwibahasa disimpan sebagai `{ id: '...', en: '...' }` dan di-resolve otomatis saat render berdasarkan path halaman (`/id/` vs `/en/`).
- **Zero string terduplikasi antar bahasa.** 28 halaman berbagi `data.js` dan skrip render yang sama; yang beda hanya chrome statis (nav, heading) via partial per bahasa.
- **hreflang & JSON-LD dibangun runtime dari `data.js`** — tidak bisa drift dari sumber fakta.
- **Fakta belum final = badge "Menunggu konfirmasi", bukan tebakan.** Konsisten di seluruh situs.

### 4.2 CTA registrasi diganti total
- Klaim tanggal "Pendaftaran dibuka Agustus 2026" **salah** dan dihapus dari seluruh situs — tidak diganti tebakan lain (tanggal buka registrasi memang belum ditentukan).
- Modal sekarang mengarahkan unduh aplikasi 20FIT ("Jadi yang Pertama Tahu" / "Be the First to Know") dengan dua tombol store terpisah.

- Modal tidak lagi auto-popup; hanya muncul saat tombol ditekan. Ditambah focus-trap + kembalikan fokus ke pemicu saat ditutup (aksesibilitas).

### 4.3 Dokumen brief rahasia dihapus dari repo
Ditemukan sendiri saat sweep compliance: `docs/PROMPT-CLAUDE-CODE-IWHM-2026.md` (salinan brief) memuat nama sponsor asli dan inventory benefit yang menurut aturan brief sendiri tidak boleh masuk repo. **Sudah dihapus** (PR #6). Dua referensi nama sponsor yang tersisa di `FACT-LEDGER.md` juga sudah diredaksi.

### 4.4 Struktur `data.js` dipertahankan (bukan di-refactor)
Diusulkan mempertahankan pola per-field `{ id, en }` daripada memecah jadi dua pohon top-level — lebih tahan-drift dan sudah jadi SSOT. Disetujui, tidak ada refactor.

### 4.5 Deploy Railway diperbaiki via Dockerfile
Railpack (builder default Railway) gagal mendeteksi situs statis tanpa penanda bahasa. Solusi paling deterministik: `Dockerfile` berbasis `caddy:2-alpine` yang menyajikan repo apa adanya, dengan redirect root `/` → `/id/` (302, karena `/en/` menyusul) dan header cache terpisah (aset 1 tahun, HTML 5 menit). Diverifikasi lokal dengan binary Caddy asli (Docker Hub diblokir egress di lingkungan kerja, jadi image `caddy:2-alpine` tidak bisa di-build; binary + config + file tree yang sama diuji sebagai gantinya).

## 5. Verifikasi yang dijalankan

- **Compliance grep** (dari checklist brief sendiri) di seluruh repo: `bri|brimo` → 0, klaim tanggal lama → 0, harga hardcode → 0, `<form>` → 0, paritas nama file id/en → identik.
- **28 halaman balas HTTP 200** dari server statis lokal.
- **Headless-browser sweep** semua 28 halaman: tidak ada JS error atau kegagalan inject partial (satu-satunya "error" adalah blokir Google Fonts oleh egress proxy sandbox — tidak berpengaruh ke pengunjung production).
- **hreflang, JSON-LD, dan language switcher** diverifikasi dengan membaca `<head>` yang benar-benar ter-inject di browser nyata, dua arah (ID↔EN).

### Keterbatasan lingkungan yang perlu diketahui
- Font Fredoka/Barlow **tidak termuat di screenshot** karena headless Chromium di sandbox tidak bisa menembus egress proxy ke Google Fonts. Layout akurat, rendering font tidak. Di browser pengunjung normal, font muat seperti biasa.
- Situs benchmark (PLN, Borobudur) tidak bisa dibuka dari sandbox (egress diblokir) — pola arsitektur diambil dari deskripsi di brief, bukan inspeksi langsung.
